# Дипломный проект «Судоку» (Kotlin + PostgreSQL)

Дипломная работа студента Пастухова Сергея Аркадьевича на тему
**«Разработка мобильного приложения “Судоку” для игровой студии»**.

## Состав репозитория

- `diploma/Дипломный_проект_Судоку_Пастухов_С_А.docx` — готовый Word-документ
  диплома, сформированный по требованиям СПО (А4, Times New Roman 14 pt,
  межстрочный интервал 1,5, поля 3/1,5/2/2 см, абзацный отступ 1,25 см,
  выравнивание по ширине, сквозная нумерация страниц).
- `generate_diploma.py` — Python-скрипт, который собирает документ
  целиком (титульный лист, задание, содержание, четыре главы, заключение,
  список источников и приложения).

## Технологический стек проекта

| Слой | Технология |
| --- | --- |
| Язык программирования | **Kotlin** (клиент и сервер) |
| Мобильный клиент | Android + Jetpack Compose + ViewModel + Coroutines + Flow |
| Локальное хранилище | Room (SQLite) |
| Серверная часть | Ktor 2.x + Exposed ORM + HikariCP |
| СУБД | **PostgreSQL 16** (JSONB, UUID, расширения uuid-ossp/pgcrypto) |
| Миграции БД | Flyway |
| Аутентификация | JWT (RFC 7519) + BCrypt |
| Платежи | Google Play Billing |
| Реклама | Yandex Mobile Ads SDK |
| Push-уведомления | Firebase Cloud Messaging |

## Сборка документа

```bash
pip install python-docx
python3 generate_diploma.py
```

После запуска в каталоге `diploma/` появится готовый файл
`Дипломный_проект_Судоку_Пастухов_С_А.docx`, который можно открыть
в Microsoft Word, LibreOffice Writer или WPS Office.
