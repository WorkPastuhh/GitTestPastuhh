# Судоку — Мобильное приложение

Мобильное приложение "Судоку" для игровой студии. Разработано на React Native (Expo) с TypeScript.

## Описание проекта

Приложение представляет собой полнофункциональную мобильную игру Судоку с турнирной системой, системой подписок на темы оформления и механизмами внутриигрового взаимодействия.

## Функциональные возможности

### Игровой процесс
- Генерация головоломок четырёх уровней сложности (Лёгкий, Средний, Сложный, Эксперт)
- Алгоритм гарантирует единственность решения для каждой головоломки
- Система заметок (карандашные пометки)
- Подсказки с автоматическим заполнением клетки
- Подсветка конфликтов и одинаковых чисел
- Таймер и подсчёт ошибок
- Отмена последнего действия (undo)
- Пауза с сокрытием игрового поля

### Турнирная система
- Создание и участие в турнирах
- Рейтинговая система ELO
- Таблица лидеров
- Призовой фонд

### Темы оформления
- 6 тем (2 бесплатных + 4 премиум)
- Классическая, Тёмная, Океан, Закат, Лес, Полночь
- Система подписок для доступа к премиум-темам

### Монетизация
- Бесплатный план с базовым функционалом
- Premium подписка (199 ₽/мес) — все темы, безлимитные подсказки, турниры
- Pro подписка (399 ₽/мес) — создание турниров, эксклюзивный контент

### Профиль и статистика
- Регистрация и авторизация
- Детальная статистика по каждой сложности
- Серия побед (streak)
- Лучшее время

## Алгоритм генерации Судоку

1. Создаётся пустая сетка 9×9
2. Заполняются три диагональных блока 3×3 случайными перестановками чисел 1–9
3. Остальные клетки заполняются методом backtracking с рандомизацией
4. Из полностью заполненной сетки удаляются клетки в зависимости от сложности
5. После каждого удаления проверяется единственность решения

## Формула расчёта очков

```
score = BASE_SCORE × difficulty_multiplier 
      - elapsed_seconds × 2 
      - hints × 50 
      - errors × 30 
      + streak × 10
```

Множители сложности: Лёгкий ×1.0, Средний ×1.5, Сложный ×2.5, Эксперт ×4.0
