# Рабочий шаблон дипломной работы

## Тема дипломной работы

Разработка мобильного приложения "Судоку" для игровой студии.

## Исходные данные проекта

В рамках дипломного проекта разрабатывается мобильное приложение "Судоку". Клиентская часть планируется на языке Kotlin. Для хранения пользовательских данных и результатов игры используется PostgreSQL. Приложение должно поддерживать основной игровой процесс, сохранение прогресса, статистику, а также дополнительный функционал: турниры между пользователями, подписку на темы оформления и механизмы внутриигрового взаимодействия.

## Цель проекта

Цель проекта состоит в разработке мобильного приложения "Судоку" для игровой студии, которое объединяет классический игровой режим, хранение пользовательских данных, систему турниров и элементы монетизации.

## Задачи проекта

1. Исследовать предметную область мобильных игр на примере логической игры Судоку и определить требования к мобильному приложению.
2. Провести анализ существующих мобильных приложений Судоку и сравнить их по функциональности, пользовательским оценкам и особенностям реализации.
3. Сформировать функциональные и нефункциональные требования, включая надежность, безопасность и обработку персональных данных.
4. Разработать архитектуру программного обеспечения, UML-диаграммы и модель базы данных для хранения пользовательских данных и результатов игры.
5. Реализовать мобильное приложение Судоку на Kotlin с использованием PostgreSQL для хранения данных.
6. Реализовать дополнительный функционал: турниры между пользователями, подписку на темы оформления и механизмы внутриигрового взаимодействия.
7. Оценить экономическую эффективность разработки и предложить бизнес-модель монетизации, включающую подписку, внутриигровые покупки и проведение турниров.

## Требования к тексту

Текст дипломной работы нужно писать простым и понятным языком. В каждом абзаце должна быть одна основная мысль. Технические термины нужно использовать точно, но без перегрузки. При описании реализации важно объяснять не только что сделано, но и зачем это нужно именно для данного проекта.

## Требования к источникам

Юридическую информацию нужно проверять по указанному источнику "юрист консультант". Если требуется ссылка на норму права, в тексте лучше ставить пометку [источник], а затем подбирать точный нормативный документ. ГОСТы нужно брать только с официальных источников. Для требований к качеству и проектированию можно дополнительно использовать ISO/IEC и IEEE.
